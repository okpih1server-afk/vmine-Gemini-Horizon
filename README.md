# Veinminer for Horizon Engine (Inner Core)

Портована версія мода **Veinminer** для мобільного рушія Horizon / Inner Core (Minecraft Bedrock / PE).

## 🚀 Особливості
- Автоматичне рекурсивне руйнування жил руди та дерев.
- Підтримка всіх ванільних руд (вугілля, залізо, золото, алмази, редстоун, лазурит, смарагд) та блоків деревини.
- Налаштовуваний ліміт одночасного руйнування блоків (`MAX_BLOCKS = 64`).

## 📂 Структура проекту
- `main.js` — основна логіка мода на JavaScript.
- `mod.info` — метадані мода для Horizon.
- `build.config` — конфігурація збірки для CoreEngine.

## 🛠 Установка
1. Завантажте цей репозиторій або розархівуйте zip-архів.
2. Помістіть папку з модом в директорію `games/com.mojang/mods/` на пристрої.
3. Запустіть Horizon та активуйте мод у списку.
